# Peacock

A two-player Forge 1.20.1 pack: frontier logistics on Tectonic terrain. Create and
Steam 'n' Rails over Geolosys ore that is never where you live, Serene Seasons and
Tough As Nails setting the calendar, villages worth defending, and a boss ladder that
hands back the technology a dark age took away.

The pack is managed with [packwiz](https://packwiz.infra.link). Mods are never
committed — `pack/mods/*.pw.toml` pins each one to an exact version and hash, and the
installer fetches them. Everything you can edit lives in `pack/`.

## Layout

```
pack/                 the packwiz pack — this is what gets installed
  pack.toml           name, versions, index hash
  index.toml          every file below, hashed (regenerate with `packwiz refresh`)
  mods/*.pw.toml      one file per mod (145; 3 server-only)
  resourcepacks/      Fresh Animations (Modrinth-managed)
  shaderpacks/        Complementary Reimagined + Unbound (Modrinth-managed)
  config/             shipped configs; `preserve = true` files are not overwritten on update
  defaultconfigs/          server configs copied into new worlds (Big Cannons: no block damage)
  config/defaultoptions/   first-launch options.txt + keybindings.txt (Default Options)
  patchouli_books/         The Settler's Almanac (in-game guide; tools/gen-almanac.py)
  kubejs/                  data overrides + server scripts (almanac hand-out, Geolosys→Create zinc)
  peacock/launch.jar       pre-launch: packwiz sync + profile apply (PEACOCK_PROFILE)
  peacock/profiles/<tier>/ potato | low | medium | high | ultra — *.keys files (one setting per line), generated by tools/gen-profiles.py
instance/             Prism instance.cfg / mmc-pack.json for reference (Forge 47.4.16)
tools/                validate.py (CI), gen-profiles.py, gen-almanac.py, build-launch.sh, launch/Launch.java (source of launch.jar)
server/               pterodactyl/ (egg + install script), start.sh (bare metal), server.properties, JVM args
pack/peacock-server/  server-only config overrides, shipped by the pack, copied over the server root on start
docs/                 PLAN.md (phases), DECISIONS.md (why things are the way they are)
```

## Install (Prism Launcher)

1. Create an instance: **Minecraft 1.20.1**, **Forge 47.4.16**, Java 17 (a current build —
   Prism's bundled 17.0.15 crashes on macOS 26+; Settings → Java → Download Java → 17, newest).
   - Memory: 6 GB on a 16 GB machine (`-Xmx6G`), 8 GB if you have 32 GB.
   - JVM args: `-XX:+UseG1GC -XX:MaxGCPauseMillis=50`
   - On a Mac, `java -version` must say `aarch64` — Rosetta Java halves performance.
2. Put `launch.jar` in the instance's **Minecraft Folder** (Prism: right-click instance →
   *Minecraft Folder*; not the instance folder one level up). In a terminal:

   ```
   mkdir -p "<minecraft folder>/peacock" && curl -L -o "<minecraft folder>/peacock/launch.jar" \
     https://raw.githubusercontent.com/Nublys/peacock/main/pack/peacock/launch.jar
   ```
3. Instance → Edit → Settings → **Custom commands** → Pre-launch command:

   ```
   "$INST_JAVA" -jar "$INST_MC_DIR/peacock/launch.jar" https://raw.githubusercontent.com/Nublys/peacock/main/pack/pack.toml
   ```
4. Same Settings page → **Environment variables** → add `PEACOCK_PROFILE` = your hardware tier
   (see below). Leave it unset for `medium`. The names are Complementary's own preset names, so the
   shader menu (`O`) shows the same word as your profile.
5. Launch. The first run downloads the packwiz installer, syncs the pack (a few minutes), and
   applies the profile. Every later launch re-syncs to `main` and re-applies the profile —
   without touching settings you have changed in-game.

### Hardware profiles

Named by what the machine is, never by its OS. `PEACOCK_PROFILE=` one of:

| profile | for | shaders | Distant Horizons | render dist. |
|---|---|---|---|---|
| `potato` | iGPU, old or hot laptop, <16 GB | off (Complementary Potato preset if you turn them on) | 96, no transparency | 6 |
| `low` | iGPU with some headroom (Vega 8, Iris Xe) | Complementary Reimagined, Potato preset | 128 | 6 |
| `medium` *(default)* | fanless thin-and-light, 16 GB (MacBook Air) | Complementary Reimagined, Medium | 192 | 8 |
| `high` | laptop with a real GPU and cooling | Complementary + Euphoria, High | 256 | 10 |
| `ultra` | desktop with a dedicated GPU | Complementary + Euphoria, Ultra | 384 | 12 |

A profile works per setting, not per file: it writes a setting only if it is still at a profile
default; once you change something in-game it is yours. Change the variable and relaunch to switch tiers; set `PEACOCK_RESET=1` for one launch to
re-apply the profile over your own edits. `PEACOCK_OFFLINE=1` launches without syncing.
macOS note: the Euphoria variant needs more texture units than Apple's OpenGL 4.1 offers, so Macs
stay on plain Complementary (`low`/`medium`).

> Converting an instance that used the old pre-launch command: just replace the command (step 3)
> and add the variable (step 4); `packwiz-installer-bootstrap.jar` already being present is fine.
>
> The repo is public so the raw.githubusercontent.com URLs work without a token.

## Server

Pterodactyl: import `server/pterodactyl/egg-peacock.json`, create a server from it, one
allocation (voice chat shares the game port). Every start syncs the pack from `main`.
Full runbook in [`server/README.md`](server/README.md) — install, pregen, overrides, rollback;
bare-metal `server/start.sh` as the alternative. Server-only mods (Spark, LuckPerms) carry
`side = "server"` and never reach clients.

## Updating the pack

```
cd pack
packwiz modrinth update <slug>        # or: packwiz update --all
packwiz refresh                        # rewrites index.toml + pack.toml hash
cd .. && python3 tools/validate.py     # must pass
```

Commit `pack/`, open a PR. CI re-runs `packwiz refresh` and fails if the index is stale.

Adding a mod: `packwiz modrinth add <slug>` (or `packwiz curseforge add <slug>`), then set
`side = "client"` in its `.pw.toml` if it is client-only.

## Keybinds (shipped defaults)

| Key | Action |
|---|---|
| `B` | Backpack |
| `K` / `O` | Toggle shaders / shader menu (shader preset per profile; Macs: plain Complementary only) |
| `M` | Atlas · `P` place atlas pin |
| `R` / `U` / `N` | Recruits: command / team / map |
| `I` | Village Expansion wiki |
| `V` | Quiver (Supplementaries) |
| `Shift+1–4` | Doggy Talents whistles |
| `,` / `.` | Voice chat menu / mute mic (voice activation by default; `Right Alt` push-to-talk) |
| `Alt` | Create tool menu / toolbelt, Railways bogey menu (context) |

Controlling is installed — search any bind by name in Options → Controls.
