Hardware-tier profiles, applied by peacock/launch.jar: the tier picked in game (/peacock profile, saved in
kubejs/config/peacock-profile.json), else PEACOCK_PROFILE, else low (potato | low | medium | high | ultra).
Generated by tools/gen-profiles.py - edit TIERS there, not these files.
_previous/ is not a profile: it lists defaults older pack versions wrote, so the launcher
can tell an untouched old default from a player's own change.
